# Endless Runner (GDevelop)

A 2D endless runner made in GDevelop 5 for my Semester 1 mid-term at Seamedu.
The character runs on its own — jump over hazards, collect coins, and see how far you get.

## Features
- Auto-running platformer character with jump, smooth camera and tweened animations
- Endless platform generation (ground and floating platforms)
- Hazards that damage the player, hearts and a health bar with a health cap
- Coin collecting with a coin counter and distance counter
- Main menu, Rules, Credits and Settings screens
- Sound and music volume sliders
- "Rage quit" key to leave a run instantly

## Built with
GDevelop 5 (event sheets, no code)

## Controls
- Jump: Space
- Rage quit: Escape

## Status
Core gameplay loop works. A few bugs left to fix.
